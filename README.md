# Zomato Pune Restaurant EDA

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a Zomato restaurant dataset from Pune.

The main objective is to analyze restaurant ratings, locations, cuisines, costs, and other factors to understand restaurant trends and customer preferences.

## 📂 Dataset

* Dataset: Zomato Pune Restaurant Dataset
* Original records: 12,189
* Records after removing duplicates: 12,134

## 🔍 Analysis Performed

The project analyzes:

* Restaurant ratings
* Restaurant locations
* Approximate cost for two people
* Popular cuisines
* Online ordering availability
* Table booking availability
* Top-rated restaurants
* Restaurant distribution by locality
* Other useful restaurant trends

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Key Insights

The analysis helps identify:

* Highly rated restaurants
* Popular restaurant locations
* Common cuisines
* Pricing patterns
* Online ordering and table booking trends

## ▶️ How to Run

1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the Python file or Jupyter Notebook.
4. Make sure the dataset file is in the correct folder.
5. Run the code to perform the analysis.
